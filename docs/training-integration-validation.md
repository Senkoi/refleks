# Windows / KovaaK's 集成验收

## 自动验证

Windows CI 执行 `go test ./...`、14 项 Python SCE 测试、`npm run build` 和 Wails 打包。
新增回归覆盖相邻同名行、乱序/重复成绩、重启、预算内模板选择、显式模板优先、完整基线、原生档位和 Windows 文件占用。
真实 SCE 压缩包测试需要 `REFLEKS_TEST_SCE_ARCHIVE`；在线发现需要 `REFLEKS_LIVE_DISCOVERY=1`，默认 CI 不运行这两项可选测试。

## 真实游戏验收（待执行）

1. 退出原版 RefleK's，备份 `.refleks` 配置。启动新 Alpha，确认 History、Benchmarks、设置及旧记录正常。
2. 在游戏保存真实 VDIM JSON/PLO，导入后对比源文件与生成列表的顺序、次数和显式角色。测试各玩家档位以及显式模板优先规则。
3. 自动选择时提供长、短两个模板；短预算应选择放得下的完整模板。显式选择过长模板应提示不足，原计划保留。
4. 连续生成并安装，确认只有一个自动列表槽位。游戏占用文件时若覆盖失败，应保持原文件、所有权标记和用户列表完整；关闭游戏后可重试。
5. 重启游戏加载 Local Playlist，执行普通异名序列及 `A×2 → A×1 → B×1`。相邻同名行按计划次数归集；异名场景额外重复继续计入当前行。
6. 中途暂停、恢复、重启应用，确认旧成绩不重复计入；游戏中跳过行后进度可校正。工作台跳过按钮只修改记录进度，不控制游戏列表。
7. 手动提前结束、跳过行、预算到时后重新生成，均不应解锁探索；完整记录原模板每行后才允许在剩余预算追加同目标探索。
8. 在计时截止前完成一局并延迟写出成绩，确认两分钟归集窗口中只计一次；截止后的对局不计入本次。新计划生成前等待延迟记录归集完成。
9. 首次在线场景加载后确认磁盘是否留下文本 `.sce`。稳定文件出现后评估，变化中失效，同名不同哈希保持冲突；已生成计划不改变。只有 BIN 缓存时保持待评估。
10. 在线同步 benchmark，检查已同步版本中的最新选择、原生档位、共享场景多成员关系与离线缓存；不能将 VDIM 模板档位或 benchmark 组标签视为已拟合场景难度。
11. 无边框窗口测试提醒、声音与焦点；独占全屏测试声音。预算到时不强制结束游戏。

## 未完成能力

SCE 几何和家族难度标定、BIN 解码、分享码直接展开列表、真实游戏自动切关状态和 AI 动作分析均未宣称完成。
自动构建成功不替代以上游戏验收。
