# 当前文件采集与剩余缺口

## 已经取得什么

- 286 个场景身份及其 303 条 benchmark 归属、原生门槛。
- 81 张中间组场景的官方元数据双匹配。
- 15 份历史真实 .sce 的结构事实、源地址与 hash。

**尚未取得能确认对应当前版本的 benchmark .sce。**历史同名文件不能代替它们。没有这些文件，不能按用户指定的方法给出当前家族难度算法。

## 首轮所需文件

先取得 `collection-pilot-names.txt` 中的 81 张图：VT S5 Intermediate 18 张、Viscose S2 Medium 39 张、rA S5 Intermediate 24 张。之后根据家族覆盖，使用 `collection-all-names.txt` 补齐初级/高级变体。

游戏官方提供的路径是：Online Scenarios 搜索精确名称 → 点击下载箭头 → Offline Scenarios 找到已下载图。若需要展开依赖，可从离线图进入 Edit 并确认 Unpack。官方说明见 [Intro to Scenario Creation](https://wiki.kovaaks.com/en/home/KovaaK%27s/ScenarioCreation/Intro)。

通常本地场景目录：

```text
<Steam 游戏安装目录>\FPSAimTrainer\Saved\SaveGames\Scenarios
```

这里的 `<Steam 游戏安装目录>` 指含游戏文件的安装根目录，常见末级文件夹本身也叫 FPSAimTrainer；完整路径可能因此连续出现两个 FPSAimTrainer。以 Steam 的“浏览本地文件”定位，再进入内部 `FPSAimTrainer\Saved\SaveGames`。

首次优先直接提供已下载的 `.sce`。若文件中有外部地图或 profile 引用，再按解析结果补相应 `.map`/profile，避免先要求复制整个游戏。不能假定进入过在线挑战就已经保存全部离线场景。

## 用户侧最少操作

可以一次性打包已有 `Scenarios` 文件夹提供给研究阶段；我们根据精确内部 Name 和文件 hash 筛选已有文件、列出缺项，不需要用户逐个给图分类。若没有完整清单，先提供已有部分也能完成第一批当前文件核验。

不需要 UE4SS、游戏中插件、修改游戏进程或额外注入。当前准备阶段也不需要上传账户凭据、Steam 配置或全部个人 stats。

建议同时附一条简短说明：打包日期、KovaaK’s 版本、文件是刚下载还是旧缓存、是否手动修改过。文件内部 GameVersion 和文件系统时间不能单独证明这是服务器当前内容。

## 接收后的核验合同

1. 解压到研究隔离目录，保留原文件；不得修改或覆盖用户游戏目录。
2. 核对文件头 Name、扩展名、大小、编码、内容 hash；相同名字多版本保留多条记录。
3. 对照 286 张清单和 leaderboard ID；无法证明当前对应关系的文件留在候选区。
4. 解析活动依赖，输出 missing dependency 清单，不以默认值补齐缺失文件。
5. 核对地图、命中盒和武器，生成原始特征表；尚未验证的特征明确标 unknown。
6. 再与原生门槛、社区证据和相近时段玩家成绩关联，决定哪些样本可以进入算法选择阶段。

## 缺口与解除方式

| 缺口 | 当前状态 | 解除方式 |
|---|---|---|
| 当前场景文件 | 0 张确认通过版本核验 | 提供游戏中下载的 .sce，或找到可追溯的当前作者分发源 |
| 当前文件→排行榜绑定 | 尚未建立 | 名称/作者/下载时间/版本记录及游戏内核验；不能只按文件名认定 |
| 地图几何、缩放、实际运动语义 | 历史结构已探查；当前实机未验证 | 当前文件解析 + 少量代表场景的游戏观察/记录 |
| 跨家族同难度标签 | 作者宽区间与社区候选已有；逐场景未确认 | 分数目标、同类玩家配对、作者具体说明互证 |
| 独立成绩配对 | 公开接口可读，外部报告已审查；完整原始配对未重算 | 冻结采样时间/版本/人群后采集；做覆盖及选择偏差审查 |
| 分类冲突 | 已列出 | 以实际武器、目标运动、计分和任务要求确认，保留原生分类 |

这些属于算法输入的真实缺口，不是需要用户再次批准才能继续的权限问题。当前可自主完成的公开资料准备已完成；拿到当前文件之后，可以继续到算法确定前的最后一轮特征和标签核验。
