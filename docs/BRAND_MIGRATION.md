# 瞄瞄品牌迁移审计

基线：`fix/automatic-player-training`，`0d656945007c29e7e04db9581b7490715f187981`。

## 替换范围

- Go 模块名及内部导入：`aimmeow`；产品名称：瞄瞄 / AimMeow。
- 窗口、侧栏、分享图水印、欢迎页、导出文件、提醒、自定义主题说明、开发环境和 README。
- 黑猫端举石墨灰 AK 的正式透明 PNG 主形象、应用 PNG / Windows ICO / 页面图标，统一柔紫主题；素材与提示词见 [BRAND_ASSETS.md](BRAND_ASSETS.md)。
- 可执行文件与安装包 / 便携包 / 校验和：`aimmeow`；版本 `0.11.0`。
- 自动更新使用 `Senkoi/refleks`。仓库暂未改名；改名时须同步更新此处及前端外链。
- 移除原作者赞助与 Discord 入口；支持入口指向参与指南，尚未配置自己的收款入口。
- 中文说明使用瞄瞄第一人称；按钮、数据单位、场景名和段位名保持清晰准确。
- 上传无默认服务器；旧设置中的上传开关不会绕过此限制。仅显式配置同步服务时提供上传选项。

## 有意保留的原名称

| 保留项 | 原因 |
| --- | --- |
| `LICENSE`、版权、原作者链接与历史研究文档 | 来源和原有研究记录必须准确保留 |
| `~/.refleks`、`.refleks` 成绩文件和序列化格式 | 延续旧成绩、录像与配置，避免复制或改写用户数据 |
| `refleks.*` localStorage 键、主题事件 / 样式元素 ID | 保留界面偏好；无需为品牌变化清空状态 |
| `app.refleks.desktop` 单实例锁及 `AppData/refleks.exe` WebView2 目录 | 同一个历史目录不能由原版和瞄瞄同时写入 |
| `REFLEKS_*` 环境变量 | 兼容旧配置；`AIMMEOW_*` 新名称优先 |
| `Refleks-Adaptive-Current.json` 兼容读取 | 已开始的旧计划不改动；下一份安全迁移到新槽位，仅清理哈希验证通过的自有旧槽位 |
| 安装 / 自启代码中的旧 exe、注册表名称 | 升级时清除失效入口，而非新产品标识 |
| `api.refleksapp.com` Benchmark 目录 | 真实的原项目外部只读服务，保留清楚署名与本地备用目录 |
| `X-Refleks-*` 上传协议头 | 用户显式配置兼容服务时保留协议，默认不发送 |
| `Reflex Arena`、`Reflex Flick`、`reflex_window` 等 | 游戏 / 场景 / 机制的名称，与产品品牌无关 |

## 发布与验收

代码和安装包已转为瞄瞄；GitHub 仓库重命名、脱离 fork 网络、正式发布和收款渠道不由这次代码迁移执行。

Windows 实机须验收：旧记录及主题继续读取、首次安装与覆盖升级、自启入口、游戏内列表显示 / 旧暂停计划续接、浮层、FFmpeg 回放和 WebView2 偏好。WebView2 显式沿用旧数据目录，避免 exe 改名后丢失 localStorage 界面偏好。
