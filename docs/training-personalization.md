# 个人训练记录、受控试练与低频观察

实现日期：2026-10-04；规划版本：8。依据 [复测证据与实施规格](research/retest-protocol-2026-10-04.md)。旧协议见 [版本 7 记录](training-personalization-v7.md)。频率、局数、负荷分组与进阶门槛都是待验证的产品参数，不是文献证明的最佳处方。

## 执行顺序

1. 自动选择仍首先续接 24 小时内的未完成 VDIM 主线，跳过实际完成的行，部分行只补原定剩余次数。
2. 没有需要续接的内容时，按分类能力、近期训练量、距上次训练时间加权；待观察/旧复测没有分类优先权。
3. 保留真实模板顺序及目标、个人成绩目标与固定局数。未完整定级的子类分数仍可用于训练水平，不因缺少评估变成 entry。
4. 完成基础模板、稳定个人历史和本地严格同族关系允许两局试练；不增加强制前测、迁移保留图或到期链。等待旧复测不阻止新试练。
5. 在正常选中的主线内按需安排低频观察；不重放已完成内容，不改变已生成/执行的列表。

## 日常记录与个人锚点

保持同图、CSV Hash、游戏版本、设置、时长、倍率分离。最近 45 天的完整正常记录用于成绩；保留低分和零分。旧历史没有当时文件证据时，仍是未绑定历史，不补写今天的 SCE 哈希。

使用全部场景共同形成训练会话，沿用设置中的 `SessionGapMinutes`（默认 20 分钟）。每个会话取场景中位数，再对最多六个会话的中位数汇总，每个会话最多十二局，防止重复刷局支配结果。至少三局、两个本地训练日且波动受控才形成稳定锚点；14 天未练标为需要更新。

记录计划、模块、模块内运行序号、会话序号、同图序号、此前可见的总练习量、同图/同分类练习量、协议以及成绩是否有效。会话是日志分组，不等于睡眠或真实热身状态。

训练暴露与成绩有效性分开：暂停、倍率变化、不完整等 CSV 可以说明练过，即使不能用于成绩比较。没有 CSV 的重开、其他游戏与此前练习均为未知。文件绑定仍仅来自执行时观察到的未变本地文件，不证明游戏实际加载了相同字节。

主线分数目标仍为稳定中位数加 `max(MAD, 2%)`；这是目标而非学习判定。进入邻近档位挑战或以改善趋势支持挑战时，额外要求至少三个可比本地训练日，单日重试不能代替。

## 两局试练

继续按直接历史、严格本地同族尺寸关系及可选反馈选择邻近变体。偏难暂避七天；偏易或已掌握时寻找下一邻近变化。默认两局，最多占可用对局预算的 10%，可用预算是总时间的 90%。不足整局时不安排。

试练保存固定两局，不用额外重试替换低分。历史参照明确为历史中位摘要，不命名为实验前测，也不把两张图的原始分数差解释成提升。试练完成状态为 `observed`，没有 24～72 小时到期链。

旧版响应回放保留；新协议不复用旧版固定前后测证明预测能力。新计划目前保守使用直接历史与同族方向参照；新协议模型获得同协议、同上下文配对与未来整日验证前，不获得决策权。长期变化不拟合成某个变体的因果收益。

## 低频固定观察

候选触发条件：已有跨日记录但波动较大、锚点长期未更新、多个训练日持续下降，或自上次观察后已积累至少三个训练日的同锚图探索。近期同版本/签名、相同模块位置的固定记录能够覆盖需要时，直接复用。

限制：

- 每计划最多一个锚图。
- 新增观察按实际开始时间计频率，同分类滚动七天最多一次，所有分类合计最多两次。
- 新增时间不超过 `min(180 秒, 总预算的 10%)`；全部对局加起来仍不超过总预算的 90%。
- 四局完整协议放不下时延后；没有开始的替换草稿不占频率，未完成的已开始观察仍占频率。

协议为“一局熟悉 + 连续三局测量”，保存四局身份以及后三局原始顺序/分布，中位数不打乱原始顺序。这是可靠性待验证的候选。

观察嵌入原本要练的模块。原定两局可补两局形成四局：实际导出四局，只计两局主线进度；记录 ID 共享。若主线接近填满预算，可以在生成阶段为真实候选预留补充时间，保持前段顺序，尾部留给下次续接。不能为了观察跳到后面的锚图。

低分、零分不删除。暂停、倍率/设置/文件变化、记录中断、运行序号不连续时标为不足或不可比；追加重试不能修复原固定样本。原本已有四局的普通主线也可以按生成时的固定取样规则提供观察，不额外计测量时间。

## 自然后续观察

自然练到同图时，匹配场景身份、文件、CSV/设置签名、协议、模块位置、会话对局序号和此前练习量的分组。不能匹配就继续记录个人水平，不产生可比变化。

不建立三天补测期限。显示实际小时数，区分当日、跨日、72 小时以上的较长间隔；跨午夜不等于睡过一晚。不自动补偿时间间隔，也不把这些间隔混合成有统计保证的趋势。

同一观察窗口展示期间可见的总练习、同图、同分类及各试练场景。一次变化属于共同窗口，不重复归因到每一个变体。观察变化可见，未校准前不显示置信区间、MDC 或因果收益排名。

## 兼容与工作台

旧版 7 的已生成、暂停/执行列表不被升级重写；已有前后测保持旧协议与原窗口，页面明确标为旧协议。新旧结果不混合。草稿替换后，对应未开始试练/观察保留为未开始；重启保留记录、频率与主线次数。

工作台显示个人历史、试练、低频观察、三局分布、实际间隔及已记录暴露。计划时间分别统计主线和新增观察，避免共享时间重复计算。两秒钟仍是轻量时钟；原始运行上下文、逐局 ID 和 SCE 原始字段不发送至工作台。观察和试练各最多保留 128 条，上下文最多 45 天/5000 条。

## 验证与尚需实机检查

自动回归覆盖：试练不绑前测、不被旧复测阻断、24 小时续接、分类加权不受旧复测影响、评估共享次数、预算与滚动频率、完整主线预留、低分/零分/重试、不完整/暂停/设置与文件变化、全场景会话、无效成绩仍计暴露、20/23/24/72/144 小时间隔、不同运行位置不比较、重启、旧列表/协议保留、至少三个训练日进阶及工作台裁剪。

Go 内部包竞态检查、前端测试/构建及 Windows amd64 交叉编译通过。尚需 Windows 实机确认实际 CSV 到达、同名连续模块、导出列表次数、重启续接和长历史界面响应。

协议可靠性、未来日预测质量和等训练时间的长期收益仍需玩家数据验证；自动化检查不能代替这些验证。本轮不增加依赖、场景上传、UE4SS 或付费模型调用。
