# 个人锚点、同族试练与隔日复测

实现日期：2026-10-03；规划版本：7。研究规格见 [机制定案](research/personalized-scene-selection-2026-10-03.md)。本文记录已实现的行为，默认阈值属于产品参数，尚未通过玩家对照实验确定最佳值。

## 已实现的执行顺序

1. 自动选分类仍先检查 24 小时内的未完成 VDIM 主线，按已完成次数续接。
2. 没有符合条件的续接时，优先选择有到期复测的分类；否则使用分类水平、近期训练负荷和距上次训练时间排序。手动指定分类/模板仍生效。
3. 到期复测占用实际计划预算；剩余时间安排主线。只有完整复测模块能放下时才安排，不拆分测量。
4. 已完成过当前模板主线、存在稳定个人锚点及受控本地变体时，可安排“前测 → 主线 → 两局试练”。没有这些证据时继续原有有界进阶逻辑。
5. 前测、试练和复测均不记入 VDIM 行完成次数。主线目标显示个人进步分数，列表局数保持固定。

生成后的计划、场景证据和列表保持固定；新成绩、反馈和场景更新用于后续生成。

## 个人锚点

| 项目 | 当前规则 |
|---|---|
| 时间窗口 | 最近 45 天；14 天未练标为需要更新 |
| 身份条件 | 同图、最新 CSV Hash、游戏版本、灵敏度、FOV、DPI、时长、目标缩放和时间倍率分开处理 |
| 有效记录 | 完整结束、正常倍率、无暂停、无作弊标记；保留低分和零分 |
| 抑制重复刷局权重 | 相隔至少 30 分钟形成新训练块，最多最近 6 块，每块最多 12 局 |
| 汇总 | 每块先取中位数，再对块中位数取中位数；波动为块间 MAD |
| 稳定条件 | 至少 3 局、跨 2 个本地训练日、正分数，MAD / 中位数不超过 15% |
| 主线进步目标 | 稳定中位数 + max(MAD, 中位数的 2%)；不增加固定列表次数 |

CSV Hash 与 SCE SHA-256 是不同来源，不假设二者相等。旧日志只作为未绑定本地版本的同图历史，不能用当前文件哈希倒填。

新记录只有在生成计划与接收成绩时，本地文件仍为同一已解析版本、且文件已在对局开始前被观察到，才记录执行时本地文件上下文。文件绑定锚点必须独立满足至少 3 局、跨 2 日，汇总时排除未绑定日志。该上下文仍不能证明游戏实际加载的字节完全相同。

成绩、命中率和有效命中速度组合评估。有效命中速度提高且成绩未下降时，单独的命中率下降不会被判为退步。

## 本地同族差分

本地扫描自动解析和缓存 SCE，不需要上传。严格同族匹配哈希包含全部配置及完整 Map Data，只排除根部名称/描述/编辑标签，以及可达非玩家角色的命中盒尺寸。

只有以下条件满足时才进行尺寸对照：

- 除目标尺寸外，机制、评分、时限、其他配置和地图数据完全一致。
- 引用可解析；没有重复字段、无法识别的配置行或冲突本地版本。
- 目标角色一一对应，半径与高度按同一比例缩放；角色之间不能一部分变难、一部分变易。
- 分类与训练目标相容，且文件配置通过已有评估检查。

差分按角色记录 `-log2(变体半径 / 锚图半径)`。不同角色缩放比例不一致时保留向量，禁止拟合单一标量响应。

这提供同族精度需求方向，不能提供跨家族总体难度、角尺寸标定或段位换算。缺少严格关系时不会凭名称相似建立关系。

## 试练与测量

| 阶段 | 固定次数 | 汇总与条件 |
|---|---:|---|
| 锚图前测 | 3 | 第 1 局熟悉，后 2 局中位数 |
| 可选独立保留图前测 | 3 | 同一测量协议；位于整套主线和变体之外 |
| 同族变体试练 | 2 | 两局中位数；额外重试不替换原记录 |
| 锚图复测 | 3 | 试练完成 24～72 小时内；第一局开始也须在窗口内 |
| 可选独立保留图复测 | 3 | 同一保留图、文件与设置；两次测量之间额外练过则取消迁移判断 |

默认先试邻近的较高精度变体；锚图被用户标为偏难时，可试较低精度变体。已稳定练过的变体优先使用直接历史。偏难反馈暂避 7 天；偏易反馈或稳定成绩明显超过上次试练时，跳过已掌握变体。

两局试练最多占可用训练预算的 `min(variety, 10%)`。可用预算为用户总时间的 90%；前测/复测按实际局数另行扣除，并保证至少一局主线可安排。预算不足时延后试练，不缩短协议。带独立保留图时，前测合计还需不超过可用预算的 25%。

同一分类有等待/到期试验时不会继续叠加新试练。替换未执行草稿会将对应试验标为未开始；已记录的观测与试验结果会保存，重启后保留。

文件变化、测量设置变化、缺少前测或超出窗口时停止比较。保留变化分别比较同图的前后成绩，迁移变化分别比较独立保留图的前后成绩；不直接比较两张图的原始分数。

## 个人响应模型

首版只拟合统一缩放比例的同族尺寸轴，响应为配对前测/试练的对数成绩比。模型使用固定原点和少量收缩，不同时求玩家绝对能力和场景绝对难度。

进入候选加权前，必须满足全部条件：

- 当前锚点具有跨日的本地文件上下文；样本为同一锚图、文件、CSV 签名和设置的可比配对。
- 至少 6 次配对、跨至少 3 个训练日、至少 2 种尺寸差分。
- 时间顺序留出最近的完整训练日，直到留出部分至少 2 条记录；训练部分至少 4 条记录。同一天不会拆到两边。
- 留出对数 MAE 比“预测成绩比为 1”的锚图基线至少改善 10%。
- 候选差分处于已观测范围内；不跨家族外推。

回测通过后才用条件预期成绩调整候选权重。零分配对会阻止对数模型启用，保留原始失败记录，避免只用成功样本拟合。样本不足、误差没有改善、角色缩放不一致或候选超范围时，回退到历史及配置方向参照。

这不是总体难度模型或因果收益估计，也未完成留出未知变体、跨家族预测及等训练时间的调度策略对照验证。

## 工作台与资源限制

新增“训练评估”页，展示个人锚点、证据来源、试练状态、复测窗口、同图/迁移变化，并提供可选偏易/合适/偏难反馈。计划页面分别统计主线、前测/复测、挑战和试练时间。

两秒时钟刷新仍只传轻量状态；完整评估沿用修订号/数据指纹缓存。原始 SCE 字段、逐局测量、运行文件上下文和历史计划不发送给工作台。持久化最多保留 128 个试验、45 天且最多 5000 条运行上下文。

## 验证与剩余实机检查

已覆盖：严格同族/冲突拒绝、历史与文件绑定隔离、按训练块汇总、速度/精度趋势、预算不足回退、两局反馈、前测与主线分账、暖身局排除、24 小时续接优先、隔日复测、设置变化、保留图练习污染、重启保存、响应回测及拒绝外推。

用户提供的 58 个真实 SCE 均可解析，原审计的 8 组受控尺寸配对通过新比较流程。原始压缩包不入仓库；设置 `REFLEKS_TEST_SCE_ARCHIVE` 后可运行真实文件回归测试。

Go 内部包竞态检查、前端测试/构建及 Windows amd64 交叉编译通过。尚需 Windows 实机确认：

1. 固定列表包含前测/主线/试练，游戏中的次数与工作台一致。
2. 重启后继续固定计划，前测不推进主线行记录。
3. 实际 CSV 写出、同名连续模块切换和本地 SCE 更新均被正确接收。
4. 隔日出现复测，换设置或额外练习保留图时显示停止比较的状态。
5. 长历史和大型本地库下的界面响应、内存与后台更新耗时。

以上自动化检查验证实现行为；长期训练收益需要玩家持续数据和对照实验。
